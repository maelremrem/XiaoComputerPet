# Roadmap

## Implemented in v2

- large full-screen minimal face: rounded-square eyes + eyebrows only
- idle gaze, blink, curious, sleepy, focused, bored, happy, excited and surprised expressions
- mood / energy / affection system
- persistent XP and levels
- unlockable peripheral accessories
- total and daily Pomodoro statistics
- daily streak when BLE-synced local time is available
- optional time-based sleep animation
- double-click interaction
- selectable completion / break / pet sound presets
- four selectable graphical pet personalities
- BLE Web configuration and browser time sync

## Possible next additions

- battery percentage on the BLE page
- low-power OLED dim/off policy
- accelerometer tap/shake interactions on XIAO nRF52840 Sense
- one-button mini-games
- custom melody editor with note sequences stored in flash
- import/export configuration JSON
- installable PWA
- BLE DFU workflow
- optional haptic motor
